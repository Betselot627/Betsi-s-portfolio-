# Betselot Tigistu - Portfolio Website

A modern, clean, and fully responsive personal portfolio website built with React and Tailwind CSS.

## Features

- **Hero Section**: Professional introduction with call-to-action buttons and smooth animations
- **About Me**: Personal introduction with statistics and achievements
- **Skills**: Visual representation of technical skills with progress bars and icons
- **Projects**: Showcase of 6 projects with descriptions, technologies, and links
- **Services**: Overview of offered services with clean card layouts
- **Contact**: Contact form and social media links
- **Footer**: Copyright and social media icons

## Design

- **Color Scheme**:
  - Background: Dark Blue (#0D3B66)
  - Text: White (#FFFFFF)
  - Accent: Light Blue (#5BC0EB)
- **Fully Responsive**: Works seamlessly on mobile, tablet, and desktop
- **Smooth Animations**: Fade-in, slide-in, and hover effects
- **Modern Typography**: Inter font family

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open your browser and visit `http://localhost:5173`

### Build for Production

```bash
npm run build
```

## Customization

### Update Personal Information

1. **Hero Section** (`src/components/Hero.jsx`):
   - Replace the placeholder photo with your actual photo
   - Update the tagline if needed

2. **About Section** (`src/components/About.jsx`):
   - Update the introduction text
   - Modify statistics (years of experience, projects, clients)

3. **Skills Section** (`src/components/Skills.jsx`):
   - Add or remove skills
   - Adjust skill levels

4. **Projects Section** (`src/components/Projects.jsx`):
   - Update project details
   - Add your actual project links

5. **Contact Section** (`src/components/Contact.jsx`):
   - Update email, phone, and social media links
   - Configure form submission handler

6. **Footer** (`src/components/Footer.jsx`):
   - Update social media links
